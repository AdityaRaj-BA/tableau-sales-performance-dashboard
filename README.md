# 📊 Superstore Sales Analysis Dashboard (Tableau)

> An interactive Tableau dashboard built using the Superstore dataset to analyze sales performance, profit trends, regional performance, customer segments, and product categories through data visualization.

![Dashboard Preview](images/dashboard.jpeg)

---

# 📌 Project Overview

This project demonstrates practical Business Analytics and Data Visualization skills using **Tableau Public**.

The dashboard transforms raw sales data into meaningful business insights through interactive charts and filters. It enables users to identify top-performing regions, profitable categories, customer purchasing behavior, and yearly profit trends.

This project showcases skills in:

- Data Visualization
- Business Intelligence
- Dashboard Design
- Sales Analysis
- Business Analytics
- Tableau Public

---

# 🎯 Objectives

- Analyze sales performance across different regions
- Compare sales by product category
- Study yearly profit growth
- Identify top-performing cities
- Analyze customer segments
- Build an interactive business dashboard

# 📊 Key Insights

- 📌 South region recorded the highest average sales.
- 📌 Technology category generated the highest sales.
- 📌 Consumer segment contributed the largest share of sales.
- 📌 Profit consistently increased from 2011 to 2014.
- 📌 New York City generated the highest sales among all cities.
