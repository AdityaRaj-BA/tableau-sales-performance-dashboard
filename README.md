# 📊 Superstore Sales Analysis Dashboard (Tableau)

> An interactive Tableau dashboard built using the Superstore dataset to analyze sales performance, regional trends, customer segments, profit growth, and product categories through effective data visualization.

![Dashboard Preview](images/dashboard.jpeg)

---

# 📌 Project Overview

This project demonstrates practical **Business Analytics** and **Data Visualization** skills using **Tableau Public**.

The dashboard transforms raw sales data into meaningful business insights through interactive charts and visual reports. It enables users to identify high-performing regions, profitable product categories, top cities, customer purchasing behavior, and yearly profit trends.

This project showcases skills in:

- 📊 Data Visualization
- 📈 Business Intelligence
- 📉 Sales Analysis
- 📌 KPI Reporting
- 📊 Dashboard Design
- 📋 Business Analytics

# 🎯 Objectives

# 📊 Key Insights

- 📌 South region recorded the highest average sales.
- 📌 Technology category generated the highest overall sales.
- 📌 Consumer segment contributed the largest share of revenue.
- 📌 Profit consistently increased from **2011 to 2014**.
- 📌 New York City generated the highest sales among all cities.
